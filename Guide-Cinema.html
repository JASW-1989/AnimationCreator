Koma 0.3 Cinema Preview

Local-only / zero required subscription / original animation fixtures

Open Koma-Cinema-Demo.html first. Save Project before closing: the disposable demo does not use your normal project vault.

Controls

Click one of six shot thumbnails. Use play, left/right or the seek bar. Space toggles playback; arrow keys step frames. Camera X/Y/Zoom edits the last camera key of the selected shot, preserving the rest. Layer checkboxes change visibility; actor hold controls the drawing clock, independently from camera motion. Effect controls change actual project data.

The three review buttons show final composite; no effects; or no effects and fixed camera. PNG/APNG/ZIP export the final composite, not the selected diagnostic view. Save Project exports JSON. Undo/redo use the same session as the old workspace.

Persistent server

node server.cjs

Node 20+; no npm install. Open the printed loopback URL, load examples/ember-gate.koma.json, then open the sequence workspace. Back up old projects first; do not expose the server to the public internet. External agent accounts are optional and not included in the app.

Scope

The demo has five action pose drawings, not continuous finished combat. It does not include general rigging, actual drawing tools, image generation, tracking, dialogue or an editable sound timeline. The MP4 sound study is separate offline assembly. The camera is 2D parallax, not a 3D orbit. See README.md and docs/Anime-Capability-Review.html for the roadmap and measured test scope.

Legacy workflow

The prior Chinese guide is retained at docs/Legacy-v0.2-Guide.zh-TW.md. Those five plugins apply to legacy scenes. They are not all migrated to the new sequence renderer. In particular Contact IK is still limited to the built-in cat, and legacy patch commands are rejected on a cinema scene.
