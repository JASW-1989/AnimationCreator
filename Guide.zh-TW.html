01 / 啟動與保存

先開啟 Koma-Atelier-Study.html 體驗原生線稿案例。此檔不自動保存，修改後請按 Save project 匯出。正式製作建議使用本機伺服器。

node server.cjs

需要 Node.js 20 或以上，不需安裝 npm 套件。開啟終端顯示的本機位址，按 ATELIER / 作畫。完整備份請匯出 Session 或備份整個 .local 資料夾。不要只複製其中一份 JSON。

02 / 一條可以實際操作的修稿流程

建立或選擇畫稿

使用 Native study 或 Create clean-line layer。點陣圖片可作參考，不會自動轉成有解剖意義的骨架。

繪製線稿

在 rough 畫動作底稿，在 line 畫正式輪廓，在 correction 留修正筆記。正常合成不顯示粗稿與修正筆記。

上色與改線

在 Paint 選色，用 seed 點擊封閉區域。使用 node 拖動輪廓後，受影響色塊會被標示 stale；按 Rebuild seeded regions 重建。

處理歧義

色域分裂或合併不會自動通過。分裂候選需要檢視後接受；合併衝突需刪除舊指派再重新下種子。

保護原稿

單格修改預設先 Fork current exposure。確實要改共用素材時，才勾選 Allow shared source edit。所有修改命令不會自動解鎖保護部件。

審核與輸出

用 Pipeline 檢查相依關係與核准狀態，再用 Compare 檢查修改前後差異。上游更改會使相關核准需要重審，不是永久有效。

04 / Codex 與本機 MCP

此套件不需要 Codex 才能編輯或輸出。串接時請在支援本機 stdio MCP 的宿主使用以下程式：

node /absolute/path/to/koma-studio/tools/mcp.cjs

必須先啟動 server.cjs。要取得 PNG 預覽，還必須開著同一伺服器的瀏覽器工作台；獨立 HTML 不是伺服器工作者。版本與編輯鎖必須檢查，不應強制跳過保護。

scene_read
scene_edit_lease(acquire)
atelier_read(expectedRevision)
scene_render_image(mode="line")
atelier_edit_preview(commands, scope)
scene_render_image(mode="diff", planId)
scene_commit(planId, expectedRevision)
scene_edit_lease(release)

05 / 測試的範圍與界線

測試包含實際筆跡輸入、線色連動、伺服器重啟、stdio MCP 圖片回傳與不同用戶端寫入衝突。完整數字以 evidence/v060/test-report.json 為準。

此環境的瀏覽器政策禁止直接導覽 localhost。整合測試以測試專用的本機傳輸橋接串接真實 HTTP 伺服器、真實 MCP 子程序和 Chromium 渲染。這不等於已在你的電腦或真實 Codex 帳號上驗收。

尚未驗證：真實 Astra / computer use、實體壓感筆、所有作業系統、長片高負載、完整商業安全稽核與美術品質。此版不會自動創作解剖正確的中間姿勢，也不會只因為可以控制滑鼠就宣稱已具備專業作畫能力。
